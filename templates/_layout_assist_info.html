{{ t('Footnote boxes') }}

{{ t('What it looks at, for every detected box:') }}

{{ t('Left edge') }}{{ t("Where the book's footnote column starts, learned separately for odd and even pages. The strongest signal, and it works for small footnotes too.") }}
{{ t('Bottom edge') }}{{ t('Where footnotes end on the page. A box running below that is always wrong; ending above it is normal for stacked footnotes.') }}
{{ t('Right edge') }}{{ t('Whether a box runs past the text column. A short box is never penalised.') }}
{{ t('Height') }}{{ t('Box height against the number of text lines inside it.') }}
{{ t('Font size') }}{{ t("Footnote type size against the book's body text, read from the PDF's text layer.") }}
{{ t('Rejections') }}{{ t('The type size of boxes reviewers deleted in this book.') }}

{{ t('It learns from detector boxes with confidence of at least {c}%, and from your approvals and edits, weighted as below.', c=(la_lp.tau_trust * 100) | round | int) }}

{{ t('What it does:') }}

  • {{ t('Check this box') }} — {{ t("a box that doesn't fit the book's layout (its confidence would drop below {c}%, or one edge is far off).", c=(la_lp.flag_below * 100) | round | int) }}
  • {{ t('Missed footnote?') }} — {{ t('a candidate the detector left out (confidence at least {c}%) that fits the layout well (at least {a}% once the layout is taken into account), at most {m} per page.', c=(la_lp.rescue_min_conf * 100) | round | int, a=(la_lp.rescue_min_conf_adj * 100) | round | int, m=la_lp.rescue_max_per_page) }}
  • {{ t('Box cut short?') }} — {{ t('such a candidate overlapping a box that is already there: extending the box covers both and reads the text again.') }}
  • {{ t('Carrying your confirmations over') }} — {{ t("after each confirmation it adds the missed footnotes it is now confident about, only on pages you haven't approved. It never reshapes or deletes a box on its own.") }}
  • {{ t('Ghost boxes') }} — {{ t("where you changed what the detector predicted, the original box stays faintly visible (dashed, washed out).") }}

{{ t("Books uploaded before the detector's candidates were saved (around 8 September) can only be checked, not added to.") }}

{{ t('Citation labels') }}

{{ t('What it looks at, for every labelled part of a reference:') }}

{{ t('Shape') }}{{ t('The character pattern: 9 = digit, A = capital letter, a = lowercase letter — e.g. "A. Aaa" for an initial and a surname.') }}
{{ t('Word before') }}{{ t('The token right before it, e.g. "s." before page numbers.') }}
{{ t('Word after') }}{{ t('The token right after it.') }}
{{ t('Word before + shape') }}{{ t('Both together, e.g. a number after "t." is a volume.') }}
{{ t('Position') }}{{ t('Which part of the reference it is (1st, 2nd, …), and roughly where in the reference it sits, each with its shape.') }}
{{ t('Length') }}{{ t('How many tokens it has, and whether it is a number.') }}
{{ t('Exact text') }}{{ t('The text itself, e.g. "op. cit.".') }}

{{ t('All of it is kept separately per citation type (normal, ibidem, …). It switches on once a book has at least {n} labelled parts in {r} references.', n=la_np.n_min, r=la_np.min_refs) }}

{{ t('What it does:') }}

  • {{ t("Suggests a different label when this book's own evidence disagrees with the stored one clearly, and on at least two features. It never relabels anything on its own.") }}
  • {{ t('Labels the viewer does not show (FootnoteMarker) are never suggested.') }}

{{ t("It learns mostly from the model's own labels, so a mistake the model makes consistently across a book can be learned as the norm — keep or change a suggestion to correct it.") }}

{{ t('Consistency checks') }}

{{ t('Where a part starts and ends follows one principle: the smallest span that still holds all of its information. Whitespace and , ; : at its edges never belong to it; a full stop belongs to it only when it closes an abbreviation ("op.cit.", "et al.", "J."), never after a number ("12." → "12"); a short letter token before a number ("pp.", "S.", "Bd.", "nr") is a prefix and stays outside ("pp. 210" → "210").') }}

{{ t('Each book also learns its own span rules from what you do: every part is reduced to its label and the shape of its neighbours ("aa." for "pp.", a full stop after a number, …). Where your edits and approvals disagree with the principle, they win — mark "pp. 210" whole as Pages and the rest of that book\'s "pp. N" parts follow. Once a rule has at least {n} of your actions behind it and none against it, it is applied to pages you have not approved on its own (undoable); before that it is a suggestion.', n=la_span.min_support) }}

{{ t('Other checks:') }}

  • {{ t('A list of pages in one part is split into one part per page ("272, 281"); a range stays whole ("15-43").') }}
  • {{ t('A year with a letter ("2005a") is split into year and suffix; things that are not a year, a DOI or a web address, and backwards page ranges, are pointed out.') }}

{{ t('Measured on the verified books before being switched on; rules that disagreed with them (for example about "op. cit.") are off.') }}
